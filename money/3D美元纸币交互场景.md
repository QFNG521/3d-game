# 3D 纸币交互场景

**请创建一个基于 Web 的超写实 3D 交互式 $100 美元纸币场景。** 以下是完整的需求规格和技术指引。

## 技术栈

- React + Vite
- React Three Fiber (@react-three/fiber) 作为 3D 渲染框架
- three.js 作为底层 3D 引擎
- @react-three/postprocessing 做后处理效果
- @react-three/drei 仅用于辅助工具（如 Environment HDR）
- 不使用任何物理引擎库（如 Rapier、Cannon），物理模拟完全手写

## 核心功能

### 1. 纸币布料物理模拟

纸币使用 **Verlet 积分 + Position-Based Dynamics (PBD)** 实现软体物理：

- 将纸币网格划分为高密度粒子网格（建议 40-50 x 24-30），粒子越多表面越丝滑
- 实现四类距离约束：**结构约束**（相邻粒子）、**剪切约束**（对角线）、**弯曲约束**（跳1-2个粒子）、**长程弯曲约束**（跳3-4个粒子）
- 关键：美元是**硬纸**不是软布，弯曲约束的刚度应远高于结构约束（接近1.0），这样纸币无法尖锐折叠，从根本上避免自穿透，不需要实现自碰撞检测
- 每帧进行 12-16 次约束求解迭代
- 实现**速度钳制**：限制每帧最大粒子位移，防止粒子穿隧
- 地面碰撞需要在积分后、每次约束迭代后、以及最终各做一次硬夹紧（triple-layer floor clamping）
- 地面碰撞时需要做速度反射（阻止反弹）和摩擦（衰减水平速度）

### 2. 区域拖拽交互

**不要使用单点拖拽**（会导致帐篷状的几何感和穿模），而是实现区域拖拽：

- 点击时，以点击位置为中心，在一定半径内标记所有粒子
- 每个粒子根据到中心的距离赋予一个权重（使用 smoothstep 衰减：中心=1，边缘=0）
- 拖拽时，所有被标记的粒子按权重跟随移动，中心粒子完全跟随，边缘粒子部分跟随
- 被强标记的粒子（权重>0.5）应跳过 Verlet 积分（不受重力影响）
- 约束求解器中，两端都是强标记粒子的约束应跳过（保持刚体区域）
- 拖拽平面应在 pointerdown 时固定（相机朝向平面），之后不再重建，用增量计算目标位置（当前射线交点 - 起始射线交点 + 起始粒子位置）。如果每帧重建平面会产生反馈循环
- 拖拽距离需要钳制，防止纸币飞出画面

### 3. 相机控制

**不要使用 OrbitControls**（在 MacBook 触摸板上会与纸币拖拽冲突），改为：

- 触摸板/鼠标的所有指针操作专属纸币拖拽
- 相机用**键盘控制**：方向键/WASD 围绕纸币旋转视角，滚轮缩放
- 相机始终看向原点（纸币中心），使用球坐标系管理相机位置
- 限制极角范围（不能看到地面以下）和距离范围

### 4. 吹风效果

- 提供吹风按钮，开启后四角固定（pinned），纸币悬浮在空中
- 风力用正弦/余弦函数叠加，基于时间和粒子位置产生波动，看起来自然
- 关闭吹风时释放四角

### 5. 重置功能

- 通过 forwardRef + useImperativeHandle 暴露 reset 方法
- 将所有粒子重置到初始平铺位置

## 纸币设计（你需要自行设计细节）

纸币正反面纹理使用 **Canvas 2D API 程序化生成**，不使用任何外部图片。创建 CanvasTexture 后设置 SRGBColorSpace 和 anisotropy=16。

### 正面应包含：

- 奶油色/淡黄绿色的纸张底色，带纸张纹理噪点
- 装饰性多层边框，带角落花饰
- 中央一只**可爱的猫咪头像**（替代富兰克林），在椭圆画框中，有交叉阴影背景。猫咪需要有：圆头、尖耳（内耳粉色）、大眼睛（带虹膜渐变和高光）、三角鼻、嘴巴、胡须、腮红等细节
- 两枚印章（联邦储备印章和财政部印章），带锯齿外环、文字环、中心字母
- 序列号、面额数字 "100"、"FEDERAL RESERVE NOTE"、"THE UNITED STATES OF AMERICA" 等文字
- 细节装饰：扭索纹（guilloche）、微缩文字、车床纹（lathework）、安全线、红蓝纸纤维、水印

### 背面应包含：

- 类似的底色和边框
- 中央**独立厅建筑**图案（带塔楼、尖顶、钟表、柱子、窗户、台阶、门）
- "UNITED STATES OF AMERICA"、"IN GOD WE TRUST"、"ONE HUNDRED DOLLARS"、"100" 等文字
- 同样的装饰细节

**重要：背面纹理需要水平翻转 UV 坐标**，因为背面 mesh 使用 BackSide 渲染，不翻转的话文字会是镜像的。

### Canvas 绘制要点：

- 画布尺寸建议 2048px 宽，按美元比例计算高度
- 所有元素需要用缩放因子（如 2.5x）放大，否则在 2048px 画布上文字和细节太小看不清
- 使用深绿色系 ink 颜色（如 #0d2b06），不要用太浅的颜色否则在3D场景中会看不清

## 材质与渲染

- 正面材质：MeshPhysicalMaterial，FrontSide，带 bumpMap 模拟纸张凹凸
- 背面材质：MeshPhysicalMaterial，BackSide
- 两个材质使用同一套 bumpMap
- bumpMap 用灰度 Canvas 生成：中灰底色 + 随机噪点 + 短线纹理 + 边框凸起
- clearcoat 微量（0.05）模拟纸张微光泽
- 使用两个 mesh（前后）共享相同的顶点位置，分别渲染正反面

## 场景设置

- 白色/近白色地面（roughness 高，metalness 0）
- 柔和漫射光照：暖色环境光 + 暖色主光 + 冷色填充光 + 边缘光
- 可选：HDR 环境贴图（如 apartment）增加反射真实感
- ACESFilmic 色调映射
- 后处理：环境光遮蔽（推荐 N8AO 而非 SSAO，后者需要 NormalPass 容易报错）、微量 Bloom、色差（ChromaticAberration）、暗角（Vignette）
- 背景色与地面协调，偏暖白

## UI 界面

- 底部居中工具栏：毛玻璃效果（backdrop-filter: blur），圆角，微阴影
- 按钮：吹风切换（含状态样式）、重置
- 顶部居中提示文字（浅灰色，小字）："拖拽纸币 · 方向键/WASD旋转视角 · 滚轮缩放"
- 全局 cursor: pointer

## 性能注意事项

- 预分配临时 Vector3 避免动画循环中创建对象产生 GC 压力
- 所有纹理、几何体、材质用 useMemo 缓存
- 约束数组在初始化时一次性创建
