# 2026-11-24

## CLANG! 2.5D 复刻（clang-25d/）
- 需求：复刻 https://clangclang.top/（《CLANG! 哐当！·拆机试炼场》），原作为美漫废土机械 FPS，要求做 2.5D 版。
- 考据：官网 JS 包提取到核心机制——4 把枪（手枪/冲锋枪/霰弹枪/G43 穿甲）、钩索、手雷、处决回血、每两关三选一卡牌、每 5 关 Boss、30 关；视觉为深褐底 + 网点 halftone + 琥珀金标题带红色硬阴影。原站在软件渲染下会拒绝启动，无法直接截图实机，故按官网首页 + 文案还原风格。
- 实现路径：与 gun-range / cs-bloodstrike 同栈——本地 three.js r159 UMD + 单文件 HTML，file:// 双击可玩。
- 2.5D 方案：**真 3D low-poly 模型 + 正交侧视相机 + 手动三层视差**（far .24 / mid .54 / near 1.22 相对速度），玩法约束在 x/y 平面，z 仅做纵深错位。此方案在正交投影下必须手动移动视差层，z 深度本身不会产生视差。
- 内容：6 类敌人（电锯机/枪手机/无人机/炸弹车/塔盾机/狙击机）+ 6 种 Boss 攻击组合（冲撞/扇形弹幕/砸地冲击波/机炮/激光/召唤）；16 张改装卡；Raycast-free 的 2D 射线-圆命中 + 爆头/护甲减伤/弱点窗口；钩索锚点、抛物线手雷预览、处决、连杀评级。
- 踩坑记录：
  - 敌人出生太远（±9.5~25）在 1440×900 正交视野外，改为 ±6.5~11.5 才稳定入镜；Boss 原本固定 x=18 也改为相对玩家 ±10 出生。
  - 正交相机下地面平面要足够深（140×120，z=34）才能填满下半屏；前景剪影过高会挡住玩法层。
  - 调试接口 aimAt 必须同步设置 playerModel.root.position/scale.x，否则 getWorldPosition 拿到旧矩阵，命中测试假失败（游戏本身没问题）。
  - 移动端竖屏：装备提示面板压住风格面板、摇杆压住弹药框；改为装备面板移到左上、摇杆上移 118px、隐藏横屏提示。
- 验证：桌面 1440×900 与手机 390×844 全流程零 JS 报错；组装/击杀/卡牌/Boss/结算/重开、摇杆/开火/瞄准/换枪/手雷/钩索均通过；全兵种+Boss 混战压力测试无 NaN、无异常。
