## 3D 城市重构（METROPOLIS）
- 旧文件：`index.html`（低多边形白天城）、`index_v2.html`（赛博朋克城 NEXUS CITY），均为方块堆叠、窗户用单 mesh 贴片，较简陋。
- 新建：`index_v3.html` —— 高还原 3D 城市（单文件 HTML + Three.js r160 via unpkg importmap）。
- 主要升级点：
  - 程序化建筑立面纹理：canvas 生成墙体+玻璃窗格+随机亮灯 emissiveMap，夜晚真实发光（8 套配色材质池，按建筑尺寸 clone 纹理并设 repeat 保持窗格比例）。
  - 完整路网：7×7 路网、沥青路面、车道虚线、路口斑马线、人行道。
  - 多样建筑：退台/裙楼、楼顶设备/天线/航空警示灯、核心区超高层、中央地标尖塔、中央公园+喷泉。
  - 真实大气：Three.js `Sky` 天空 + 太阳轨迹（按高度系数驱动直射光，落山归零）+ 月光补光 + 指数雾 + ACES 色调映射；平滑日夜循环。
  - 动态：车流沿真实车道、行人沿人行道、街灯/车灯夜晚亮起、云漂移、喷泉轻微起伏。
  - 相机：OrbitControls 鸟瞰（WASD 平移）+ 指针锁定第一人称漫步（P 切换，建筑 AABB 碰撞），T 加速时间。
- 校验：`node --check` 语法通过；本地 `python -m http.server 8123` 返回 HTTP 200。
- 依赖：浏览器需联网加载 unpkg CDN（three@0.160.0 及 addons）。
