# 2026-11-26

## cinderwatch 汉化（cinderwatch/，上游 https://github.com/kevintngo/cinderwatch）
- 需求：拉取 kevintngo/cinderwatch（单文件 three.js 等距塔防，canvas 自绘 5x7 像素字体）并汉化；评估能否结合 gitee mail_osc/translate（translate.js）。
- 结论：translate.js 是扫 DOM 文本节点 + 调在线翻译 API 的运行时机翻，而本游戏所有文字都画在 canvas 上、且要求 file:// 离线单文件，无法直接接入；只借鉴了它的思路（按浏览器语言自动选择、记住选择、一键切换），改为静态 i18n + 人工翻译。
- 方案（已落地，中英双语可切换）：
  - `src/01-i18n.js`：gettext 风格，`T('English')` 返回中文，支持 `{0}` 占位；语言优先级 `#lang=` > localStorage `cinderwatch.lang` > `navigator.language`；切换走 reload，并同步改写 hash。文件名以 01 开头是为了在数据表（MON/TOWER/BIOMES）求值前加载。
  - 汉字字形：`tools/cjkpix.py` 把 BDF 位图字体中用到的字栅格化成 `src/69-cjkpix.js`（350 字 / 16KB），构建期内联，运行时不加载字体。
  - `70-pixelfont.js`：新增 WIDE 字形表、`PX.lineH()`（中文行高 13，英文 9）、`setWide()`（5x7 字形在中文行里下沉 2 行对齐）；UI 里所有 `PX.LINE` 改为 `PX.lineH()`，换行改为按汉字逐字断行、行首禁则标点。
  - `tools/check-i18n.js`：校验每条 `T()` 文案有翻译、每条翻译都被使用、占位符一致。
- 踩坑记录：
  - 字体选型：Ark Pixel 12px 缺常用简体字（燃/拖/滚/即/恐/药…，仅 18648 个表意字）；Zpix 商用收费；最终用 **Fusion Pixel 12px proportional zh_hans**（OFL，BDF 直接解析，无需 Pillow）。BDF 的 `一` 不是字框顶，字框顶要用「多数表意字未裁剪时的 top」统计得到。
  - 底部按钮栏：加了语言按钮后，"点击开启声音" 宽按钮的 fit 判断必须把它算进去，否则手机竖屏首次点击前整行溢出屏幕。
  - 无头 Chrome 在本沙箱里子进程会崩（sandbox initialization failed），需用 `CHROME` 指向一个加 `--no-sandbox` 的包装脚本；`DPR=3` 会把进程杀掉（exit 137），用 `DPR=2` 验证手机布局。
  - 沙箱里 `ps` 不可用；软件 GL 下帧率低，`rdt` 被限到 0.05，游戏时间比墙钟慢，按时间等状态的截图要改用 `__cw.UI.titleT=12` 之类强制。
- 验证：桌面 1440×900、手机 390×844 / 844×390，中英文各一遍：HUD、标题卡、提示、怪物图鉴、建造菜单、防御塔菜单、首领名、暂停、语言切换与持久化均正常，无 console 报错。
- 文档：`README.zh-CN.md`（完整中文说明）+ English README 增补 Languages 段、`lang` 参数、字体许可。改动未提交（用户未要求 commit）。
- 用户反馈右侧预览面板里"中文字显示不完全"：截图里游戏左右都被裁（页面按约 934 CSS px 宽排版，面板只露出中间约 741 px），HUD 文案本身没溢出。修复：`src/20-post.js` 用 `IntersectionObserver` 量出页面实际可见区域，写进 `R.clip`，`R.safe = R.pad(刘海安全区) + R.clip`，HUD 自动收进可见部分；普通浏览器标签页里恒为 0。用"窄面板 + 更宽跨域 iframe"的宿主页验证通过。若是 webview 类宿主（非 iframe）裁切，页面内检测不到，只能让用户加宽面板或用浏览器打开。
- 第二次反馈"汉字只显示左 2/3"才是真问题，上面那条裁切判断是误诊：`70-pixelfont.js` 把 12px 宽的汉字行位图存进 `Uint8Array`，右边 4 列被截掉，每个字都缺右侧三分之一。改成 `Uint16Array` 即修复。教训：**字形是否完整要用像素检验**（在页面里 `PX.text` 画到 canvas，读 `getImageData` 看点亮列是否到第 10 列以后），视觉模型看截图发现不了这种缺笔。
- 用户截图里页面按约 640 CSS px 宽排版但只露出 576 px（右下角"+"缩放按钮在可见范围外）；普通浏览器同宽度下全部放得下。IntersectionObserver 方案在用户面板里未见生效，原因未确认（可能是 webview 类宿主或面板未重新加载）。
