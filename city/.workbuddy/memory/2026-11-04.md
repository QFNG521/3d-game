## 新增 3D 枪械组装 + 打瓶子网页游戏（gun-range/）
- 交付 `gun-range/index.html`（单文件约 1200 行）+ `gun-range/vendor/three.min.js`（three r159 UMD，本地离线可用）。
- 技术选择：刻意用 UMD 普通 `<script>` 而不是 ES module/importmap，这样 `file://` 双击就能运行，不需要起本地服务器；所有模型、木纹/砖墙/招牌/瓶标签纹理、音效（WebAudio）都程序化生成，无外部素材。r159 是最后带 UMD build 的版本之一，控制台只有一条 deprecation warning。
- 玩法：装配台 7 个零件按序装配（3D 零件 raycast 点击 / 清单卡片 / 数字键 1-7），飞入动画 + 安装位线框 ghost + 当前目标光环；靶场第一人称，鼠标位置即射线方向（不做 Pointer Lock，准星跟随鼠标，Raycaster 打瓶子），命中后玻璃碎片/液体粒子、连击倍率、开镜加分、8 发弹匣与换弹、波次递增（会移动/浮动的瓶子、金色瓶三倍分）、清台 +5 秒、60 秒计时、localStorage 最高分、结算评级。
- 组装好的枪用同一套 `PARTS` 定义重建为第一人称 viewmodel，实现「自己拼的枪拿去打」的闭环。
- 竖屏适配：fov 76 / 开镜 60（桌面 62/38）、瓶子排布宽度收窄到 6.2、viewmodel 缩小下移、触摸开火/开镜按钮、toast 按 `pointer:coarse` 切换文案。
- 验证方式：`npm i playwright-core`（/tmp/gr-test，不污染工作区）+ 系统 Chrome `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` headless，args 需 `--enable-unsafe-swiftshader --use-gl=angle --use-angle=swiftshader`（否则 WebGL 起不来）。桌面 1440×900 与移动 390×844 全流程零 JS 报错：组装 7/7、第一波 5 瓶 100% 命中、清台进第 2 波、结算/再来一局/返回装配台、换弹/开镜/空格开火均通过。
- 保留调试接口 `window.BottleRange`（state / aimAtBottle / fire / spawnWave / phase 等）便于控制台复测。
- 低帧率下 dt 上限从 .05 放宽到 .1，避免软件渲染时装配动画被拖慢到点不动。

## 新增 CS1.5「猪圈图」3D 射击游戏（cs-bloodstrike/）
- 查证：CS1.5 俗称「猪圈图」= `cs_bloodstrike`（血战回廊 / 血战 / 厕所），**不是农场猪圈**；特征是左右绝对对称「回」字形、两端出生点、中央对枪大道、外圈环形走廊可绕后、中央混凝土掩体群、纯击杀无 C4/人质。
- 交付 `cs-bloodstrike/index.html`（单文件约 1360 行）+ `vendor/three.min.js`（复用 gun-range 的本地 r159 UMD，file:// 双击可玩）。
- 地图：44×44 外墙 + 16×16 内圈四面各留 4 宽门洞；中央矮台/箱堆、左右严格对称的箱堆立柱、CT/T 出生区、BLOODSTRIKE 发光标牌、中央引导虚线、雾中远景建筑。`WALLS` 做 AABB 碰撞，`WALL_MESHES` 做射线遮挡；BOT 沿回字航点巡逻，不做寻路。
- 玩法：指针锁定 FPS（WASD / Shift 静步 / Ctrl 蹲 / 空格跳）、USP/MP5/AK/M4/AWP/刀、后坐与准星扩散、换弹、AWP 按住右键开镜、Raycaster 头/身判定与爆头 4 倍、B 买枪菜单（$1200 起、击杀 +$400）、BOT 视线检测 + 集火节流、死亡 2.6 秒复活、25 杀或 3 分钟结算、CS 风格 HUD/雷达/击杀提示/评级。对手是低多边形训练机器人，无血腥。
- 关键坑（可复用）：
  - three.js 高 `metalness` 材质在无 envMap 时几乎全黑 → 第一人称视图模型要把 metalness 降到 .2–.4，并在 camera 上挂 2 盏补光。
  - 触摸 tap 在 headless 只派发 pointerdown/touchstart/pointerup（不合成 click），按钮要同时绑 pointerdown+touchstart+click 并做 260ms 防抖。
  - **幽灵 click**：pointerdown 弹出菜单后，同一次 tap 的 click 会命中刚出现的「关闭」按钮把菜单关掉；父元素 `pointer-events:none` 挡不住子元素显式 `auto`，必须用 `#buyMenu.guard,#buyMenu.guard *{pointer-events:none!important}` + ~320ms 后解除。
  - BOT 出生点限制在 T 半场航点、交火距离 26 米、开局/复活无敌，避免多 BOT 集火秒杀。
- 验证：playwright-core + 系统 Chrome swiftshader，桌面 1440×900 与移动 390×844 全流程零 JS 报错：移动、击杀、买 AK、换弹、死亡复活、结算重开、AWP 开镜、买枪菜单、摇杆。
- 调试接口 `window.CS`（state / pos / probe / lookAtBot / damage / openBuy / endMatch 等）。
