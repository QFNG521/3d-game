# 2026-09-23

## 新增：《下班潜行》offwork-escape.html

**需求**：用户想仿照「准时下班不被上司发现」的视频，做一个游戏。

**产出**：`offwork-escape.html`（48.7KB 单文件，零外部依赖，双击即玩）

### 设计决策
- 选 **2D 俯视潜行**（而非项目原有的 Three.js 3D 路线）：视野锥 + 巡逻路线一眼看懂，可玩性最强，也是该梗最经典的形态。3D 版本作为后续可选项。
- 流程：拿 背包 → 手机（茶水间）→ 工牌（老板玻璃办公室）→ 打卡 → 进电梯，5 步难度递增。
- 地图 44×26 格 / TILE=36：北中南三片开放办公区 + 会议室 + 老板玻璃办公室 + 茶水间 + 电梯厅。
- 字符地图：`#`墙 `H`工位 `G`玻璃(挡路不挡视线) `k`吧台 `o`绿植 `E`电梯。

### 技术实现要点
- **视野锥**：射线投射生成被墙裁切的多边形（40 条射线，步进 0.13 格），每帧每 NPC 一次；锥形颜色随警戒值 蓝→黄→橙→红。
- **视线判定** `hasLOS`：沿两点采样（步长 0.14 格）查 `blocksSight`。
- **碰撞** `areaFree(x,y,r)`：实体 AABB 覆盖的所有格子必须可走；`resolveMove` 分轴滑动。
- **NPC 状态机**：patrol / pause / investigate / chase。老板到点随机停下「看手机」（`lookT`，视野缩到 42%）；同事警戒满 → 去打小报告（把老板置为 investigate 走向玩家）。
- **告密传导**：同事先结算 alert，老板后结算，便于同事触发老板。
- 噪音系统：丢键盘（F）/ 跑动脚步 → 吸引 9.5 格内通视的 NPC 前往查看，可调虎离山。
- 美术：`staticLayer` 离屏预渲染地板/墙/玻璃/家具/暖色台灯；移动端 DPR 上限 2。
- 音效：WebAudio 纯合成（脚步噪声、拾取、警报、心跳、胜负琶音），无音频文件。

### 关键坑（踩过）
1. **`requestAnimationFrame(loop)` 在 `loop` 函数体内部也出现一次**。给脚本做字符串注入时用 `replace()` 会命中函数体内那一处，必须用 `lastIndexOf()` 定位末尾那次。
2. **mock DOM 的 `remove()` 必须真的从父节点摘除**。游戏里 `while(toastBox.children.length > 3) firstChild.remove()` 在 mock 下会死循环 → 进程被 SIGKILL。
3. 追击状态不能复用「到达路点就切回 patrol」的判定，否则 NPC 在抓到你之前会自己解除追击。追击用 `arriveDist = 0.05`。
4. `mock 的 querySelectorAll` 必须缓存返回的元素，否则 `onclick` 绑到的是另一批新对象。

### 验证方法（可复用）
无头跑真实游戏循环，而不是只做语法检查：
- `node -e` 造 mock window/document/canvas(Proxy 返回 no-op)，用 `new Function` 加载提取出的 `<script>`。
- 通过 mock 的 `addEventListener` 收集 handler，手动派发 keydown/keyup 驱动游戏。
- 注入只读探针 `window.__probe`（插在 IIFE 末尾）读内部状态，验证 NPC 位移、警戒值、通关状态。
- **BFS 连通性**：从出生点洪水填充，确认所有关键点位可达（实测 849 格，7 目标全可达）。
- **自动机器人**：BFS 寻路 + 逐帧按键，走完 5 步流程 → `state==='won'`，证明游戏可通关。
- 压测 3 万帧零未捕获异常。

## 追加：可读性补丁（用户反馈「区域没有文字标识，npc 也没有角色标识」）

**问题**：地图是纯色块，玩家不知道哪块是会议室/茶水间/老板办公室；4 个 NPC 只有颜色差别，分不清谁是老板谁是同事。

**改动**：
1. **区域名**：新增 `ZONES` 常量（10 个条目：开放办公区×2、会议室、老板办公室、茶水间、电梯厅、打卡、北走廊、南走廊、你的工位），`drawZoneLabels()` 每帧画在地面层（静态层之上、视野锥之下，这样人物会盖住文字，层次正确）。
   - 逐字绘制 + 手动字间距（不依赖 `ctx.letterSpacing`，兼容性更稳）。
   - 加 1.2px 暗影提升深色地面上的可读性。
   - 落点全部经过校验：中心格可走、按最大字号 1.9× 估算的占位不压到实心家具。
2. **角色名牌**：`drawNameTag()` 取代原来只有 `? ! 📱 💬` 的头顶符号，改为圆角名牌 —— 老板红底写「上司」、同事深底写各自姓名（小李/老张/阿May/王姐）、玩家里写「你」；状态后缀合并进名牌（`上司 📱`、`小李 ?`）。老板另加**红色虚线外环**（半径 R+8.5，画在警戒环外侧避免重叠）。
3. 同事 D 由「前台」改名「王姐」（他其实在茶水间巡逻，原名对不上）。
4. 底部 HUD 与开始菜单都补了图例说明。

**新增通用工具**（可复用）：
- `hexA('#rrggbb', a)` → rgba 字符串
- `roundRect(c, x, y, w, h, r)` —— 手写 arcTo 版本，不依赖较新的 `ctx.roundRect`
- `uiScale()` = `clamp(1/scale, .8, 1.9)` —— **关键技巧**：世界坐标下绘制的 UI 文字按此反向补偿，使名牌/区域名在屏幕上的物理尺寸保持稳定。地图缩放小时（手机竖屏 scale≈0.5）文字不至于缩成不可读。
- `charWidths(font, text)` —— 逐字宽度缓存（key 上限 240，超限整体清空），把 `measureText` 从每帧 44 次降到 5 次。

**验证**：区域标签落点 10/10 合法；4740 帧含菜单态/手机上尺寸/反复 resize 30 次，0 未捕获异常；机器人通关回归通过（背包 18 帧 → 电梯 1286 帧，state=won）。
