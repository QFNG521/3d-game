## 修复：漫步模式出生点卡在屋内
- 症状：切到漫步模式后人在房子里，方向键无效。根因是出生点硬编码 (60,60)，落进建筑 AABB；碰撞只判断目标点，第一步仍在盒内 → 永久卡死。
- 修复三处：① 出生点改为扫描 roadPaths 的中点，取「不撞房 + 不在水里 + 离镇中心最近」的点，并自动朝向中心；② 若当前位置已在碰撞盒内则放行移动（脱困保险）；③ 巷道 LANE 5.5→7.5、房屋占地上限 0.92→0.82、碰撞余量收窄，行走更通畅。
- 另外补了桥面高度采样 groundHeight()（上桥时相机抬升并平滑），漫步速度 26→20。
- 验证方式：临时挂 window.__city 调试句柄，用 puppeteer 模拟 W/A/方向键测位移；注意无头软件渲染只有 ~1.8fps，dt 被钳制到 0.1，位移要按帧数换算，别误判成"按键失效"。

## 修复：漫步模式 A/D 左右反了
- 根因：漫步模式右向量写成 `rt = (cos yaw, 0, -sin yaw)`，这是「左」方向；正确应为屏幕右 = `fwd × up = (-fwd.z, 0, fwd.x)`。
- 鸟瞰模式没反是因为它的 `fwd` 定义成「目标→相机」方向（与视线相反），同一个公式在两种模式下符号刚好相反，所以只有漫步模式暴露问题。
- 验证：取相机 matrixWorld 第 0 列（屏幕右向量）与实际位移做点积，4 个 yaw 角度下 D/→ 为正、A/← 为负，全部正确。
- 经验：判断横移方向不要靠肉眼看公式，直接用相机 matrixWorld 的第 0 列做点积回归测试。
