# 2026-07-21

## 重写《方块前线 BlockFront》（替换旧版 cs_v4）

用户对旧版不满意，全量重写。旧版核心问题：每方块一个 Mesh（~99k draw call 必卡）、纯色方块无 MC 质感、方块不能互动、代码有大量死代码。

### 新版架构（js/）
- `config.js` 常量与方块/武器/敌人/波次定义
- `noise.js` 带种子 ValueNoise + fbm 地形（中心战区压平、边缘山丘围合）
- `textures.js` Canvas 程序化 16×16 像素纹理图集（NearestFilter）+ 等距方块图标
- `sfx.js` WebAudio 全程序化音效（枪声=带通噪声+三角波轰，爆炸=低通扫频噪声）
- `world.js` **Chunk 合并网格**（16×16 chunk，面剔除，每 chunk 仅 opaque+transparent 两个 Mesh）；DDA 体素射线；分轴 AABB 碰撞
- `particles.js` 对象池粒子（方块碎屑用图集子区域 UV）+ 加法混合曳光弹
- `player.js` FPS 物理、第一人称手部（枪/方块随快捷栏切换）、射击/放置/后坐/摆动
- `enemies.js` 4 种敌人独立模型 + 苦力怕蓄爆（闪烁+膨胀动画）+ 球形弹坑破坏地形
- `game.js` 渐变天空穹顶着色器、昼夜循环（dayLight 驱动光照/雾/天色）、波次流程、屏幕震动

### 验证结果（Node mock 测试）
- 世界生成 12ms；全图 25 Mesh（面剔除率 ~90%）；chunk 重建 0.18ms
- DDA 射线、AABB 碰撞挤出、放置/破坏循环均通过

### 关键技术经验
- 体素游戏必须合并 chunk 网格，逐方块建 Mesh 是性能灾难
- 'use strict' 下 eval 不导出声明；Node 侧测试需拼接代码或挂到 global
- zsh heredoc 中 `$(...)`/反引号会被 shell 展开 → 测试脚本用 Write 工具写文件而非 heredoc

### Bug 修复记录
- **地面镂空（方块侧面消失）**：world.js FACES 表的顶点顺序原本统一写成顺时针，Three.js 默认只渲染逆时针面 → 侧面被背面剔除。修复：重写 FACES 为外侧逆时针 + 每面 UV 锚点，抽出 `buildFace()` 统一生成；用叉积验证 6 个面法线全部朝外。教训：体素 mesher 的绕向必须与渲染引擎剔除规则一致，写完后要用叉积自测。
- **波次显示异常（用户看到 189）**：代码逻辑本身波次初始为 0、startGame 只 +1，可能是浏览器缩放或显示误解。顺势加了选波次界面：菜单新增「选择波次」按钮，4×2 网格显示 1~8 波及敌人数量，通关解锁下一波（maxUnlockedWave 记录进度），startGame(wave) 支持从任意已解锁波次开始。
- **波次真跳 189（波次结束判定每帧重复触发）**：主循环里「波次结束」判定每帧执行，条件满足时每帧都 setTimeout(nextWave, 2500) → 2.5 秒后几百个定时器同时触发，wave 一口气跳几百次。修复：加 `waveCooldown` 标志，进入判定立即上锁，setTimeout 回调里解锁；respawn() 也重置。
- **快捷栏 4~7 格图标空白**：`div.innerHTML += ...` 会重新解析并重建 DOM 树，之前 `appendChild(icon)` 的 canvas 被销毁；武器格用 emoji（🔫💥）在部分系统也不显示。修复：快捷栏构建改为全部 `createElement + appendChild`；武器图标改用 Canvas 画像素枪（rifle/pistol/shotgun 三种），不依赖 emoji。
- **高处走向低处画面持续抖动**：player.js 落地逻辑用「强制贴地」（onGround 时直接把 pos.y 设为 gy+1.001），与重力下降冲突，两帧间反复拉扯导致抖动。修复：① 落地判定改为比较「期望落点」与「碰撞修正后实际落点」，被向上推才算落地，vel.y 清零，不再手动改 pos.y；② 相机 Y 加 smoothEyeY 平滑，下落/走下台階时快速插值（1 - pow(0.0000001, dt)），上升/平地直接跟随。测试：真实地形高差≥2 行走 90 帧，眼部 Y 向上跳变 0 次。
