# 2026-06-26

## 创建《方块世界：突袭》FPS 游戏

从零构建了一个融合 Minecraft 方块世界 + FPS 射击的网页 3D 游戏。

### 技术栈
- Three.js r128 (CDN)
- 纯原生 JavaScript，无框架依赖
- WebGL 3D 渲染

### 项目结构
```
cs_v4/
├── index.html          # 主页面（含完整 HUD）
├── styles/style.css    # 游戏样式（赛博朋克绿色主题）
├── scripts/
│   ├── utils.js        # 工具函数、常量、输入管理器
│   ├── world.js        # 程序化世界生成（柏林噪声地形、树木、水池）
│   ├── player.js       # 第一人称控制（移动、跳跃、冲刺、视角）
│   ├── weapons.js      # 武器系统（手枪/步枪/霰弹枪 + 子弹 + 粒子特效）
│   ├── enemies.js      # 敌人系统（僵尸 AI、寻路、攻击、血条、死亡动画）
│   └── game.js         # 主游戏循环（波次系统、碰撞检测、小地图）
└── README.md
```

### 游戏功能
- 64x64 方块世界程序化生成
- 3 种武器（手枪/突击步枪/霰弹枪）
- 敌人波次系统（难度递增）
- 小地图实时显示
- 射击/命中粒子特效
- 暂停菜单、伤害闪屏、HUD 系统
