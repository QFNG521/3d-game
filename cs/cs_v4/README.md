# 方块前线 BlockFront — MC × FPS

一个真正把《我的世界》和 FPS 射击**融合**起来的网页游戏：在程序生成的方块世界里抵御一波波怪物，子弹能击碎方块、右键能搭建掩体、苦力怕会把地形炸出弹坑。

直接用浏览器打开 `index.html` 即可游玩（Three.js 走 CDN，需联网）。

## 操作

| 按键 | 功能 |
|---|---|
| W A S D | 移动 |
| 鼠标 | 视角 / 瞄准 |
| 左键 | 射击（命中方块会直接击碎） |
| 右键 | 放置方块（选中方块栏时） |
| 空格 / Shift | 跳跃 / 冲刺 |
| R | 换弹 |
| 1~7 / 滚轮 | 切换武器与方块 |
| Esc | 暂停 |

## 玩法特色

- **三种武器**：突击步枪（全自动）、手枪（精准半自动）、霰弹枪（8 弹丸近战爆发）
- **四种敌人**：僵尸、疾行兽、蛮兽（高血重击）、苦力怕（近身蓄爆，炸出真实弹坑）
- **8 波战役 + 无尽模式**：波次清空回血，第 8 波通关后可继续无尽挑战
- **可破坏地形**：泥土/沙子一碰就碎，石头需要持续火力，砖块最硬
- **自由建造**：草方块/泥土/石头/木板随时搭掩体、垫脚、修工事

## 技术要点（相对上一版的重构）

| 项目 | 旧版 | 本版 |
|---|---|---|
| 渲染 | 每个方块 1 个 Mesh（~99,000 个） | **Chunk 合并网格：全图 25 个 Mesh** |
| 面剔除 | 无 | 邻接剔除，减少 ~90% 面数 |
| 纹理 | 纯色材质 | Canvas 程序化 16×16 像素纹理图集 |
| 方块交互 | 仅作背景 | 子弹击碎 + 右键放置 + 爆炸弹坑 |
| 音效 | 无 | WebAudio 全程序化合成（零音频文件） |
| 敌人模型 | 通用僵尸 | 4 种独立模型 + 苦力怕闪烁蓄爆动画 |
| 天空 | 纯色背景 | 渐变着色器穹顶 + 昼夜循环 + 黄昏 |

## 代码结构

```
index.html      页面与全部 UI/HUD 样式
js/config.js    常量、方块/武器/敌人/波次定义
js/noise.js     带种子的值噪声地形生成
js/textures.js  程序化像素纹理图集 + 方块图标
js/sfx.js       WebAudio 程序化音效
js/world.js     体素世界：chunk 合并网格、DDA 射线、AABB 碰撞
js/particles.js 方块碎屑/血雾/爆炸/曳光弹
js/player.js    玩家物理、第一人称手部、射击/放置
js/enemies.js   敌人模型与 AI（含苦力怕爆炸）
js/game.js      主循环、光照天空、波次流程、屏幕震动
```
